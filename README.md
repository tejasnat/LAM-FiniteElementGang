# LAM Research Challenge 3.0 — Stage 2

**Team:** Finite Element Gang

Repository for the team's Stage 2 Practical Engineering Challenge work, including the hydraulic system design, ESP32 firmware, experimental results, documentation, and demonstration media.

## Repository structure

- `documentation/` — challenge submission PDFs and supporting documents
- `firmware/` — ESP32 control and data-acquisition code
- `results/` — calibration data, plots, calculations, and observations
- `media/` — demonstration images and video links/files

## System overview

The project is a small-scale automated liquid-flow system with two operating modes:

- **Case 1 — Control + Measurement:** closed-loop process-fluid circulation with sump-level protection and flow measurement.
- **Case 2 — Flushing + Shutdown:** flush-water operation using all three pumps, followed by automated system shutdown when the flush supply is exhausted.

More detailed documentation will be added with the final submission files.
